Probeats – Maquette UX/UI Figma

# Présentation du projet
Ce projet consiste à réaliser la maquette UX/UI d’un site e-commerce pour la marque Probeats, spécialisée dans les équipements audio haute qualité.
L’objectif est de concevoir les wireframes et prototypes du futur site internet permettant au client de valider l’ergonomie, l’architecture et l’identité visuelle avant le développement.
La maquette a été réalisée avec Figma et comprend :
- des wireframes desktop
- des wireframes mobile
- un prototype interactif de la page d’accueil

# Objectifs pédagogiques
Ce projet permet de développer les compétences suivantes :
- utiliser un outil de maquettage (Figma)
- concevoir l’architecture d’une application web
- adapter l’interface aux différents supports (desktop / mobile)
- concevoir un prototype interactif
- planifier et organiser les tâches de conception
