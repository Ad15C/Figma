# Probeats – Maquette UX/UI Figma

Projet UX/UI réalisé sur Figma pour la conception d’un site e-commerce dédié à la marque fictive Probeats, spécialisée dans les équipements audio haute qualité.

Le projet comprend :
- des wireframes desktop
- des wireframes mobile
- un prototype interactif
- une réflexion UX/UI responsive

# Outils utilisés
- Figma
- Wireframing
- Prototype interactif

# Compétences développées
- Conception UX/UI
- Créations de wireframes
- Réalisation de prototypes
- Organisation d'une interface e-commerce
- Hiérarchisation des contenus
- Création d'une identité visuelle cohérente

# Présentation du projet
Probeats est une marque fictive spécialisée dans les équipements audio immersifs et haute qualité.

Le site e-commerce a été conçu pour une cible :
- jeune
- connectée
- passionnée de musique et de technologie

Produits mis en avant :
🎧 Casque audio
🔊 Enceinte Bluetooth
🎚 Enceinte studio
